# Wording for the free-k identification screen

Wording for the free-k identification screen

## Usage

``` r
.tmb_k_identification_message(ki)
```

## Arguments

- ki:

  The list returned by
  [`.tmb_k_identification()`](https://brentkaplan.github.io/beezdemand/reference/dot-tmb_k_identification.md).

## Value

A list with `issue` and `recommendation` strings, or `NULL` when the
screen found nothing.
