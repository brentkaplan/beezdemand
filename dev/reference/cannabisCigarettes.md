# Cannabis/cigarette cross-price responses

Cross-price style data with cannabis and cigarette context.

## Usage

``` r
cannabisCigarettes
```

## Format

A data frame with columns including: id (a sequential integer
participant identifier), x, y, commodity, and auxiliary fields
(CigPrice, CanPrice, variable, value).

## Examples

``` r
# data(cannabisCigarettes)
```
